## Deployment Manual — hw3_inverted_index

Этот документ описывает, как локально запустить задание **hw3_inverted_index** и получить файл с инвертированным индексом,
а также выполнить булев поиск по нему.

---

### 1. Требования

- **Java**: JDK 17.
- **Gradle Wrapper** уже лежит в репозитории.
- Перед запуском должны быть готовы результаты:
  - `hw2_tokenization/output/lemmas/*.txt`
  - `hw1_crawler/output/index.txt`

---

### 2. Что делает модуль

Модуль `hw3_inverted_index`:

- читает постраничные файлы лемм из `hw2_tokenization/output/lemmas`;
- извлекает основной текст;
- нормализует слова и приводит их к леммам;
- строит **инвертированный индекс** вида `термин -> список документов`;
- сохраняет индекс в файл `hw3_inverted_index/output/inverted_index.txt`;
- выполняет **булев поиск** по запросам с операторами `AND`, `OR`, `NOT` и круглыми скобками.

Поиск работает не по исходным словоформам, а по **леммам**, поэтому разные формы одного слова
(например, `Цезарь`, `Цезаря`) будут сведены к одному термину.

---

### 3. Сборка модуля

На Windows:

```bash
.\gradlew.bat :hw3_inverted_index:build
```

На Linux/macOS:

```bash
./gradlew :hw3_inverted_index:build
```

---

### 4. Запуск модуля

#### Вариант 1. Построить индекс и затем ввести запрос вручную

Windows:

```bash
.\gradlew.bat :hw3_inverted_index:run
```

Linux/macOS:

```bash
./gradlew :hw3_inverted_index:run
```

После построения индекса программа предложит ввести булев запрос в консоль.

---

#### Вариант 2. Передать запрос сразу через аргументы

Пример запроса:

```text
(Клеопатра AND Цезарь) OR (Антоний AND Цицерон) OR Помпей
```

Windows PowerShell:

```bash
.\gradlew.bat :hw3_inverted_index:run --args="(Клеопатра AND Цезарь) OR (Антоний AND Цицерон) OR Помпей"
```

Linux/macOS:

```bash
./gradlew :hw3_inverted_index:run --args="(Клеопатра AND Цезарь) OR (Антоний AND Цицерон) OR Помпей"
```

---

### 5. Поддерживаемые операторы

- `AND`
- `OR`
- `NOT`
- скобки `(` `)`

Также поддерживаются альтернативные формы:

- `&&` вместо `AND`
- `||` вместо `OR`
- `!` вместо `NOT`

Приоритет операторов:

1. `NOT`
2. `AND`
3. `OR`

---

### 6. Где смотреть результат

После запуска создаётся файл:

- `hw3_inverted_index/output/inverted_index.txt`

Формат строки:

```text
<термин>\t<doc1>, <doc2>, <doc3>, ...
```

Пример:

```text
алгоритм	00003.html, 00006.html, 00042.html
поиск	00002.html, 00003.html, 00098.html
```

В консоль также выводятся документы, удовлетворяющие булевому запросу, в формате:

```text
<имя_файла>    <URL>
```
